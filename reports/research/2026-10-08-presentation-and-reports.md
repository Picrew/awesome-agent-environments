## 验证与限制

以关闭 HTML 的 Markdown 渲染器生成本地预览，再用 Playwright 检查论文表、仓库表及报告索引；预览不作为新发布网站。源数据、双语生成文件、本地链接与报告位置由校验脚本检查。截图与原文缓存仅用于本地核验，不分发原论文。

本轮 GitHub 公共 API 增量查询遇到 403 速率限制，没有伪造新的 star／push 时间，也没有覆盖已有元数据快照。新识别的研究主页和 AgentENV 代码通过官方正文关联，作为配套链接展示；不在缺少元数据的情况下新增独立 GitHub 项目行。

HTTP 批量检查与内容阅读是不同证据。OpenAI 页面可通过研究浏览器读取，但本地 curl 被站点拦截；其他连接超时也保留原结果，不用缓存成功覆盖失败。当前批次和增量链接结果见[核验报告](../verification/2026-10-08.md)。

最终验证：15 项测试通过，离线核验 0 错误；240 个外链中 225 个通过、13 个连接超时、2 个被拦截。两份主目录各 47 张表、两份报告索引各 5 张表已检查列数一致。结果见[结构化审计](../verification/presentation-and-report-audit.json)。
